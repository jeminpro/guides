Algebra & sequences

Do the same thing to both sides. Sequences with a steady gap use an nth-term rule.

Letters stand for numbers

5x means 5 × x. The × is left out so it is not mixed up with the letter x. 3(x + 2) means 3 × (x + 2). To undo ×, divide.

One-step equations

Undo the operation. Whatever you do, do it to both sides.

You see Undo with Example
x + 1 = 3 take 1 x = 2
x − 1 = 3 add 1 x = 4
5x = 25 divide by 5 x = 5
x2 = 5 multiply by 2 x = 10

Two-step — undo + or − first, then × or ÷

3x + 4 = 19
1Take 4 off both sides → 3x = 15 2Divide both sides by 3 → x = 5 ✓Check: 3 × 5 + 4 = 19

nth term — when the gap stays the same

Example: 5, 8, 11, 14…

1 Find the gap 8 − 5 = 3
2 Write gap × n 3n
3 Match the first term 3n + 2

Check: n = 1 → 3 + 2 = 5. n = 10 → 30 + 2 = 32.

Substitution

Replace the letter with the number, then BIDMAS.

If a = 4, then 2a + 1 = 2 × 4 + 1 = 9
