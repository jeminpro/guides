Sequences & algebra extras

Use the term-to-term rule to continue a sequence and substitute given values into expressions.

Number sequences

Finding the nth term — step by step

Use this method only when the gap is the same each time (an arithmetic sequence).

Example: 5, 8, 11, 14…

Step 1 Find the common gap 8 − 5 = 3, so gap = 3
Step 2 Write that gap times n 3n
Step 3 Match the first term: 3n gives 3 when n = 1, but we need 5, so add 2 3n + 2
Check Put any position in for n n = 10 → 3×10 + 2 = 32

Special sequences worth spotting

Square numbers
1, 4, 9, 16, 25, 36
n × n = n² · gaps grow 3, 5, 7…
Cube numbers
1, 8, 27, 64, 125
n × n × n = n³
Triangular numbers
1, 3, 6, 10, 15, 21
Add one more each time (+2, +3, +4…)
Fibonacci
1, 1, 2, 3, 5, 8, 13
Add the two terms before it.
Powers of 2
1, 2, 4, 8, 16, 32, 64
Double each time.
Going down
20, 17, 14, 11, 8
d can be negative: d = −3 → 23 − 3n

Roman numerals

I 1
V 5
X 10
L 50
C 100
D 500
M 1000

1 · Add

When a symbol is followed by one of equal or lower value, add the values.

VI = 5 + 1 = 6 XII = 10 + 1 + 1 = 12

2 · Subtract — only these pairs

If a smaller symbol comes before a larger one, take it away instead of adding. Only I, X and C can be used this way, and only in these six pairs:

I from V or X
IV = 4 · IX = 9 X from L or C
XL = 40 · XC = 90 C from D or M
CD = 400 · CM = 900

3 · Repeat

I, X, C and M may repeat up to three times in a row.

III = 3 XXX = 30

V, L and D never repeat and are never used to subtract.

Roman → number: MCMXLIV = M + CM + XL + IV = 1000 + 900 + 40 + 4 = 1944
Number → Roman: 1944 → 1000 + 900 + 40 + 4 → M + CM + XL + IV → MCMXLIV

Going that way, split the number into thousands, hundreds, tens and ones, swap each part for its symbols, then join them up in order.

Common examples:
IV = 4 IX = 9 XIV = 14 XXIX = 29 XLII = 42 XLIX = 49 LXXV = 75 XC = 90 XCIX = 99 CDX = 410 DCLXVI = 666 MMXXVI = 2026
