Solving algebra equations

5x means 5 × x. The × sign is left out so it is not muddled up with the letter x — in the same way 3(x + 2) means 3 × (x + 2). To undo it, divide.

Equation Solution Example
x + a = b x = b − a x + 1 = 3 → x = 3 − 1 = 2
x − a = b x = b + a x − 1 = 3 → x = 3 + 1 = 4
a × x = b x = ba 5x = 25 → x = 255 = 5
xa = b x = b × a x2 = 5 → x = 5 × 2 = 10
ax = b x = ab 8x = 2 → x = 82 = 4

Two-step equations undo the + or − first, then the × or ÷

3x + 4 = 19
1Take 4 off both sides → 3x = 15 2Divide both sides by 3 → x = 5 ✓Check: 3 × 5 + 4 = 19
x2 − 3 = 4
1Add 3 to both sides → x2 = 7 2Multiply both sides by 2 → x = 14 ✓Check: 14 ÷ 2 − 3 = 4

Undo the steps in the opposite order to BIDMAS, and always do the same thing to both sides. With brackets, take the loose number off first, then divide: 2(x + 4) + 6 = 18 → 2(x + 4) = 12 → x + 4 = 6 → x = 2
